A compact arcade garden about risk, rhythm, and banking a perfect harvest. Move the lantern with WASD or arrow keys, dash with Space, and collect glowing fruit while the orchard's sentry vines wake up. Bank three fruit at the moon gate to grow the garden; bank all five harvests to win. Every harvest adds a faster vine, while missed fruit costs a heart. Mute is available in the HUD.

## Run it

```sh
node serve.ts
# open http://localhost:8080/game/
```

The game is static and offline: no packages, APIs, fonts, images, or network requests are needed.
